/spaces

/spaces



The /spaces command is used to enable or disable space preservation.

Synopsis

/spaces [on|off]

Switches

None

Parameters

on - Enable spaces preservation.
off - Disable spaces preservation.

Example

Display spaces status: 
/spaces
Enable space preservation: 
/spaces on
Disable space preservation: 
/spaces off
