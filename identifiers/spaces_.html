$spaces

$spaces



The $spaces identifier preserves spaces for the TODO - ON_INPUT event.

Synopsis

$spaces([echo | send | dcc],parms)

Parameters

echo - Echo into a window.
send - Send the message to a channel or query.
dcc> - Send the message to a DCC chat.

Properties

None

Example

; Simple autocorrect example that uses hash tables. This preserves spaces.
on *:input:*:{
  var -n %temp $parms
  var -n %temp = $regsubex(%temp,/((?<=^| )\w+)/g,$iif($hget(autocorrect,\1) != $null,$v1,\1))
  if ($left($1,1) != /) && (!$ctrlenter) {
    $spaces(send, PRIVMSG $target : $+ %temp)
    $spaces(echo, -aitc own $+(<,$me,>) %temp)
    halt
  }
}
