$trim

$trim



The $trim identifier that removes excess spaces from the left, middle or right of text.

Synopsis

$trim(text,lmr)

Parameters

l - Delete spaces from the start of the string (leading spaces)
m - Reduce consecutive spaces to a single spaces when they are not at the start/end of the string
r - Delete spaces from the end of the string (trailing spaces) Not using a parameter (default) is equivalent to using them all

Properties

None

Example

//echo -ag $len($trim(a $chr(32) $+ $chr(32) b)) is 3 but $len($trim(a $chr(32) $+ $chr(32) b,l)) is 6
